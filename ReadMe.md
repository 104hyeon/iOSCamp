# 내배캠) 4주차 과제_ 계산기앱 

## 진행단계
>-  Lv1. UILabel을 사용해 수식을 표시할 수 있는 라벨 띄우기
>-  Lv2.  UIStackView를 사용해서 4개의 버튼을 모아 가로 스택뷰 생성
>-  Lv3. UIStackView를 사용해서 세로 스택 뷰 생성 후 버튼 총 16개 배치 
>-  Lv4. 연산 버튼 (+, -, *, /, AC, =)들 색상 orangd로 설정.
>-  Lv5. 버튼 전체적으로 둥글게 만들기
>-  Lv6. 버튼을 클릭하면 라벨에 표시. 맨처음 0은 지워도록 함.
>-  Lv7. 초기화 버튼 구현.
>-  Lv8. 등호(=) 버튼 클릭 시 수식이 연산 되도록 구현.

## 앱 설명
- 기초적인 연산이 가능한 계산기앱입니다.
- 덧셈, 뺄셈, 곱셈, 나눗셈 사칙연산이 가능합니다.
- 숫자는 정수만 가능합니다.
 

## 발견된 문제
- 연산버튼 두 번 이상 연속으로 입력 후 등호(=) 버튼을 누르면 앱이 종료됩니다.

## 문제 해결
- 연산버튼이 두 번 이상 연속으로 입력되지 않도록 수정했습니다.  
- ❗️ [트러블슈팅](https://hae-on4.tistory.com/entry/4%EC%A3%BC%EC%B0%A8%EA%B3%BC%EC%A0%9C%ED%8A%B8%EB%9F%AC%EB%B8%94%EC%8A%88%ED%8C%85)

## 추후 개선 사항
- 등호를 누르고 결과값을 얻은 후 숫자 입력하면 결과값에 추가되는 문제 해결이  필요합니다.
